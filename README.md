# String Utils

Welcome to String's open source utilities repository! This is a collection of scripts, gists, and tools that we reference in our content and share with the community.

## Contents

- [`clean-choice/`](clean-choice/) — a Chromium extension that spots checkout upsells where the way to decline is visually suppressed and, on request, shows both choices as equal buttons.
